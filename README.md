# Mist
An minecraft server implementation in rust for minecraft 1.21.11

## Features
**General**
- [x] Config (.toml)

**Networking**
- [x] Inital handshake
- [x] Server info querying
- [x] Encryption
- [x] Mojang authentication
- [x] Enter play state
- [x] Chat messages
- [x] Command system

**World**
- [x] Show players in tablist
- [x] Spawning player
- [x] Synchronize players across all clients
- [x] Player skins (in online mode)
- [x] Procedual worldgen
- [x] World saving
- [ ] Lighting engine
- [ ] Biomes
- [ ] Structures
- [ ] Block entities
- [ ] Mobs
- [ ] Dimensions

**Security**
- [ ] Server-side movement validation
- [ ] Server-side action validation
- [ ] Secure chat
- [ ] Permissions
- [ ] Whitelist
